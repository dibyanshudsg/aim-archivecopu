## Owner decisions

- Issue-month release is 00:00 on the first in Asia/Kolkata. A future issue remains absent from public Browse, Search, issue detail, cover and PDF delivery until then, even if an admin has marked it published.
- The live home hero is selected separately for each magazine. The menu offers automatic newest available, previous available, and an archive issue from the same month five years earlier when available (otherwise the newest issue at least five years old). These choices recalculate each month. A hidden issue stays hidden until restored, so the next eligible issue takes its place.
- Only the currently featured issue bypasses the usual five-year PDF embargo. Existing short-lived R2 grants issued before a hide cannot be revoked; they expire under the existing five-minute grant policy. New grants stop once the hide is saved.
- Admin Settings accepts one raster image with independent main logo, favicon and social-image placements. Each placement has its own restore-to-default control. The Google Form panel is collapsed until opened.
